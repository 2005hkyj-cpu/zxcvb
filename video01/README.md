## 다시 만들기
```bash
pip install sherpa-onnx==1.12.40 soundfile numpy
# 한국어 음성 모델: https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-mimic3-ko_KO-kss_low.tar.bz2
python3 build.py --model-dir <압축 푼 폴더> [--bgm 배경음악.mp3]
# 직접 녹음했다면: python3 build.py --voice-dir <01_hook.wav ~ 10_outro.wav 폴더> --bgm 배경음악.mp3
```
대본이나 화면 문구를 바꾸려면 `scenes.json`을 고친 뒤 다시 실행하세요.
